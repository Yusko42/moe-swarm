# Проверка CI для pull request

Этот файл добавлен в ветке `test` для проверки CI при создании PR в `dev`.

1. Отправить ветку: `git push origin test`.
2. Открыть pull request: base — `dev`, compare — `test`.
3. Дождаться проверок `Build (gcc-11)`, `Build (clang-14)` и `Lint`.

Все три проверки должны завершиться успешно. Изменение только документации
тоже запускает CI: в workflow нет фильтров по путям.

Этот файл можно удалить после проверки.
