# Модуль swarm::autopilot

## Ответственность
Развёртывание по `/start`, явные фазы, монотонный `deployment_id` как токен разграничения версий. Автоматическая перестройка при изменении состава: подключение, выход/потеря узла. Старый и новый экземпляры модели одновременно не существуют. Сверяет фактическую раскладку после загрузки; расхождение > 1 слоя ⇒ `placement_mismatch`. Ошибка развёртывания/перестройки останавливает модель и возвращает рой в `idle` (ожидание `/start`), а не в `failed`.
