# Модуль swarm::dispatcher

## Ответственность
Очередь по принципу первым пришёл — первым обслужен, максимум 16 ожидающих + 1 активный. Устранение дубликатов по `request_id` (время жизни 10 минут). Отказы до создания потока — на уровне HTTP (429, 413, 409, 400). Отмена из очереди и остановка генерации. При сбое узла сохраняет исходный диалог в оперативной памяти и делает один автоматический повтор (`attempt = 2`). При роспуске/нехватке памяти отклоняет всю очередь.
