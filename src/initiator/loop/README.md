# Модуль swarm::loop

## Ответственность
Однопоточный контекст ввода-вывода, единственный источник истины. Потоки HTTP, таймеры, сигналы процессов только публикуют события. Состояний гонки нет по построению. Все предельные сроки — на монотонных часах.
