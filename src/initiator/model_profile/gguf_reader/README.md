# GGUF reader

Самостоятельный C++20 ридер метаданных и описаний тензоров.
CMake-цель `gguf_reader` использует только стандартную библиотеку C++.
Python-пакет gguf, библиотеки движка и профилировщик ей не нужны.
Формат описан в [спецификации GGUF](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md).

```cpp
#include "gguf_reader/gguf_reader.hpp"

auto header = swarm::read_gguf_header("model.gguf");
// header.version, header.alignment, header.metadata, header.tensors
```

Потребитель подключает `target_link_libraries(<target> PRIVATE gguf_reader)`.
Прежний include `model_profile.hpp` и функция `swarm::read_gguf_header`
сохранены для совместимости.

## Контракт

Поддерживаются GGUF v2 little-endian и v3 little/big-endian.
Магия проверяется до разбора; неизвестная версия отклоняется.
`GgufHeader` содержит версию, порядок байтов, размер файла, конец описаний,
выравнивание (по умолчанию 32), начало данных, сумму размеров тензоров,
словарь метаданных и описания тензоров.

`Metadata::type` сохраняет исходный числовой тип GGUF (0–12).
Значения сохраняются без фильтрации по имени ключа:

| Тип GGUF | Поле Metadata |
|---|---|
| UINT8/16/32/64 | `integers` (`uint64_t`) |
| INT8/16/32/64 | `signed_integers` (`int64_t`) |
| FLOAT32/64 | `reals` (`double`; float32 расширяется точно) |
| BOOL | `booleans` |
| STRING | `text` |
| ARRAY | `element_type`, `count` и соответствующий вектор; строки — `strings` |

Числовой или логический скаляр занимает один элемент вектора.
У массивов допускается нулевая длина. Вложенные массивы и неизвестные типы
отклоняются. BOOL должен иметь значение 0 или 1.

`TensorInfo` содержит имя, форму, ID типа GGML, относительное смещение,
абсолютное смещение и размер в байтах. Поддерживаются 36 активных типов из
llama.cpp `cd959bae99ff4bed22bef2604f45241c09bbb8c8`.
Неизвестные или удалённые типы отклоняются. Весовые данные не читаются.
Размер вычисляется по размеру строки квантованного типа и форме, без padding;
группировка `blk.<i>.*` остаётся в `build_profile()` (§4.1 архитектуры).

Проверяются границы файла, переполнения, выравнивание, дубликаты ключей и имён
тензоров, ненулевые размерности, целое число блоков в строке и пересечения.
Ошибки разбора выбрасывают `std::runtime_error` с префиксом `GGUF:`;
ошибки файловой системы могут выбрасывать `std::filesystem::filesystem_error`.

Ограничения чтения: строка до 1 MiB, массив до 1 000 000 элементов,
суммарный бюджет сохраняемых строк и значений — 64 MiB. Бюджет не является
точным лимитом RSS: служебные структуры контейнеров и их ёмкость расходуют
дополнительную память. Превышение ограничений считается ошибкой.
