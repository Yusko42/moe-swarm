# Модуль swarm::planner

## Ответственность
Чистая функция раскладки. Жёсткие ограничения — память; среди допустимых раскладок выбирается минимизирующая прогнозируемое время на токен по полосе памяти/задержке узлов. Возвращает раскладку в терминах командной строки движка + бюджеты оперативной памяти + прогноз в токенах/с либо ошибку (§6.4). Расширенная оптимизация (полоса, гетерогенность, версия 1) — вне объёма работ. Все подключённые доступные узлы, у которых хватает памяти хотя бы на один слой, получают не менее одного слоя
