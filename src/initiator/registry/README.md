# Модуль swarm::registry

## Ответственность
Узлы, лимиты (`--memory`), замеры, пары «желаемое/наблюдаемое» состояние, адаптивные тайм-ауты по фазам, разграничение версий. Хранит последние замеры недоступных узлов для `/status`, проверенные диапазоны слоёв, кэш базового замера на время жизни роя.
