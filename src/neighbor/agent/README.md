# Модуль swarm::agent

## Ответственность
Отправляет наблюдаемое состояние, получает желаемое, асинхронно приводит систему к нему. Очереди команд не исполняет. Идемпотентность по (`deployment_id`, `action`). При несовпадении идентификатора развёртывания — немедленная остановка старого RPC. При потере инициатора — самостоятельный роспуск, сообщение «Связь с роем потеряна. Память освобождена», завершение программы.
