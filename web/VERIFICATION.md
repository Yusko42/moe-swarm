Дополнительно готовая сборка проверена через HTTP: `index.html` и все четыре
ресурса (JS, CSS, favicon) доступны, пути начинаются с `./`. Dev-заглушка
в production-preview отсутствует.

Chromium завершается до открытия страницы: создание служебного Unix-сокета
запрещено окружением (`socket() failed: Operation not permitted`). Это
не результат выполнения браузерных сценариев страницы. Автоматизированные
проверки в DOM не подтверждают визуальное качество или CSS-геометрию.
Мобильная вёрстка и переполнение требуют визуального просмотра.

Для проверки в обычном окружении:

```sh
cd web
npm ci
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:ui
```

Затем пройти чек-лист в README.md и сверить тексты с ФТ-7.
